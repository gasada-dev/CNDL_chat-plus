# CNDL_chat+

> Клиентский чат-менеджер для Minecraft 1.21.11 и 26.2 на Fabric.

## Коротко о моде

CNDL_chat+ помогает управлять чатом и серверными действиями. Мод умеет:

- хранить историю чата между подключениями и показывать время сообщений;
- сохранять важные сообщения в независимые per-server закладки;
- разделять сообщения по вкладкам и искать их через `Ctrl+F`;
- различать локальный, глобальный, клановый и личный чат;
- скрывать нежелательные сообщения, слова и пользователей Discord-моста;
- уведомлять через HUD и звук по пользовательским TEXT/маске/regex alert-правилам;
- хранить друзей, показывать их статус и давать быстрый доступ к серверным командам;
- показывать временную кнопку принятия входящего запроса телепорта или автоматически принимать его по выбранной политике;
- использовать отдельные настройки для разных серверов;
- открывать по ПКМ меню игрока с копированием, ЛС, друзьями и серверными действиями.

Менеджер чата открывается клавишей **F8**. Клавишу можно изменить в стандартных
настройках управления Minecraft. Мод работает только на клиенте, устанавливать его на
сервер не требуется.

## Зачем это нужно

Мод полезен, если вы общаетесь сразу в нескольких каналах или хотите меньше отвлекаться
на нежелательные сообщения. Для каждого сервера
можно выбрать отдельный шаблон с собственными командами, форматами чата, фильтрами и
списком друзей.

Если настройки сервера отсутствуют или повреждены, мод не скрывает чат и не применяет
чужой серверный шаблон.

## Быстрый старт

1. Установите Fabric Loader 0.19.3 или новее для Minecraft 1.21.11 либо 26.2.
2. Установите Fabric API для своей версии игры.
3. Скачайте подходящий JAR из **[GitHub Releases](https://github.com/gasada-dev/CNDL_chat-plus/releases/latest)**.
4. Поместите JAR в папку `.minecraft/mods`.
5. Запустите игру, подключитесь к серверу и нажмите `F8`.

Нужные версии Fabric API:

| Minecraft | Fabric API |
|---|---|
| 1.21.11 | `0.141.6+1.21.11` или новее |
| 26.2 | `0.156.0+26.2` или новее |

## Основные возможности

### Управление чатом

- история до настраиваемого лимита с восстановлением при повторном подключении;
- вкладки глобального, локального, кланового, личного, Discord и системного чата;
- непрочитанные сообщения по вкладкам и timestamps `[HH:mm]`;
- одинаковые сообщения подряд объединяются в одну строку со счётчиком `x2`, `x3` и далее;
- поиск без учёта регистра через `Ctrl+F`;
- контекстное меню сообщения по ПКМ;
- закладки сообщений с копированием, удалением и безопасной очисткой.

### Chat Alerts

Глобальные alert-правила отслеживают только видимые сообщения после фильтрации. Доступны
TEXT, маска `*` и regex, ограничение по каналу, независимые HUD и звук. Настройки
открываются через F8 → «Настройки» → `Chat Alerts` и действуют на всех серверах.

### Закладки сообщений

Пункт `Сохранить в закладки` находится в меню сообщения по ПКМ. Закладки хранятся отдельно
для каждого multiplayer server, не зависят от включения истории и доступны кнопкой
`Закладки` над вкладками открытого чата. В singleplayer они сохраняются только до disconnect.

### Фильтрация чата

- локальный чёрный список слов и фраз без учёта регистра;
- маски `реклама*`, `*казино*` и другие варианты;
- отключение всего чата Discord-моста или отдельных его пользователей;
- серверный мут игрока через команду активного шаблона;
- скрытые фильтром сообщения не попадают в историю и вкладки.

### Друзья

- сохранённый список друзей и подсказки ников игроков онлайн;
- online-друзья идут первыми, offline-друзья сортируются по последнему посещению;
- HUD показывает до 15 online-друзей и уведомляет об их входе;
- личное сообщение, перевод денег, запрос телепорта и почта;
- подсказки кнопок показывают фактическую команду активного сервера.
- на Vanilla-box `Alt+ПКМ` по игроку открывает добавление и удаление из привата или торговца.

### Информация об игроке

Экран информации открывается кнопкой над вкладкой друзей. Ник можно выбрать из игроков
онлайн или ввести вручную. Для поддерживаемого сервера профиль загружается по кнопке
`Обновить`; при недоступности API используется настроенная серверная lookup-команда.

## Подробное поведение

### Каналы

Префикс глобального чата и маркеры каналов меняются отдельно для каждого серверного
шаблона на странице `Каналы` его редактора. Они используются вкладками, фильтрами и
контекстным меню. Формат `(!)`
распознаётся как глобальный чат; сообщения Discord-моста получают отдельную вкладку.

### Друзья и профиль

Фоновая проверка друзей использует настроенную команду вида `/clan lookup <ник>` и не
показывает служебный ответ в обычном чате. Обход начинается через 30 секунд после подключения
или раньше при открытии вкладки друзей: по пять друзей в сохранённом порядке с интервалом
10 секунд и паузой 60 секунд между группами. После timeout друг один раз проверяется повторно.
Команда, введённая игроком
вручную вне фоновой проверки, отображается как обычно.

Для шаблона `Vanilla-game` профиль игрока загружается из публичного API сервера. Мод
показывает доступные сведения: статус, клан, брак, даты регистрации и входа, контакты и
постройки. Если API не отвечает, данные извлекаются из строк lookup-ответа по шаблонным
регулярным выражениям. При отсутствии данных о браке может использоваться настроенная
постраничная команда списка браков.

### Интерфейс

- два равных раздела F8: чёрный список и друзья;
- автодополнение ников клавишей `Tab`;
- подсказки для кнопок и команд;
- кнопка «?» с описанием возможностей и управления;
- автоматическое сохранение конфигурации;
- выбор активного серверного шаблона в глобальных настройках.
- единый экран глобальных переключателей чата, Discord, HUD и звуков;
- серверные команды и форматы открываются кнопкой «Настройка команд для сервера».

## Серверные шаблоны

Шаблон хранит настройки конкретного сервера: каналы, фильтры, Discord-муты,
друзей, команды и форматы разбора ответов. Переключатели интерфейса, общего Discord-чата,
HUD и звуков действуют глобально. Встроенные шаблоны `Vanilla-box` и
`Vanilla-game` поставляются вместе с модом.

Legacy `responderEnabled`, `rules` и `periodicMessages` остаются в JSON только как
migration bridge. Загрузка, сохранение, копирование и import других категорий не удаляют их.

Выбор шаблона выполняется в таком порядке:

1. Точная ручная привязка к адресу сервера.
2. Точное совпадение адреса в шаблоне.
3. Совпадение адреса по маске.
4. Шаблон по умолчанию.

Команды личных сообщений, телепорта, мута, lookup, перевода и почты редактируются
отдельно для каждого шаблона. При переключении сервера временное состояние предыдущего
шаблона очищается. Старый конфиг переносится в `Vanilla-box` с резервной копией.

Дополнительные JSON-шаблоны можно загрузить из:

```text
.minecraft/config/cndl-chat-plus-template-imports/
```

## Конфигурация

Основные файлы:

```text
.minecraft/config/cndl-chat-plus.json
.minecraft/config/server-templates.json
.minecraft/config/server-templates/*.json
.minecraft/config/cndl-chat-plus-template-imports/*.json
.minecraft/config/cndl-chat-plus-chat-bookmarks/*.json
```

При первом запуске старые config, imports и история копируются в новые пути без удаления
или перезаписи исходных данных.

## Обновления

Один раз после подключения к серверу мод асинхронно проверяет последний выпуск на GitHub.
Проверка не запускается в главном меню и не мешает работе при ошибке сети. Установка
обновлений выполняется только пользователем. Окно показывает основные пункты из
`UPDATE_NOTES.md`; полный файл конкретной версии открывается отдельной подтверждаемой ссылкой.

Релизными файлами считаются JAR из
**[GitHub Releases](https://github.com/gasada-dev/CNDL_chat-plus/releases/latest)** с именами:

```text
CNDL_chat+-<version>-mc1.21.11.jar
CNDL_chat+-<version>-mc26.2.jar
```

## Сборка из исходников

Потребуется **JDK 25**. Gradle устанавливать отдельно не нужно: репозиторий содержит
Gradle Wrapper.

```bash
./gradlew test
./gradlew build
```

Готовые JAR появятся в `build/release/`. Процедура выпуска описана в
[`docs/RELEASE.md`](docs/RELEASE.md).

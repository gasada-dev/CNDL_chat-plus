# История изменений

## Unreleased

Следующее изменение обязано получить новую уникальную версию.

## 0.4.4 — 2026-08-03

- добавлена JUnit 5 infrastructure и characterization/unit/security test suite;
- централизованы text normalization и wildcard matching без изменения legacy semantics;
- добавлены validators для player/Discord/message/amount inputs;
- добавлены server template model, atomic repository, safe migration старого config в `Vanilla-box`, address resolver и immutable active runtime;
- команды, parsers, filters, responder guards/rules, friends/HUD и periodic scheduler переведены на active template services;
- добавлены template management UI и подтверждаемый выборочный import с preview;
- `ResponderScreen` получил верхний selector шаблона с кнопкой настроек; скрытая periodic zone закреплена в `(0,0)` размером `15×15`;
- template editor теперь редактирует команды сервера и Discord patterns, добавлены bundled templates и безопасная пользовательская папка загрузки;
- `UpdateChecker` читает latest GitHub Release и проверяет соответствие numeric tag и JAR asset;
- GitHub Actions автоматически публикует проверенный основной JAR при push тега `v<mod_version>`.

## 0.4.3

- актуализирована публичная документация проекта;
- включено исправление проверки обновлений и обхода кэша GitHub из 0.4.2.

## 0.4.2

- исправлена проверка имени JAR со знаком `+` в ссылке GitHub;
- устранено ошибочное повторное URL-декодирование `%2B`;
- запрос `version.json` теперь обходит пяти­минутный кэш GitHub;
- тайм-аут проверки увеличен до 10 секунд.

## 0.4.1

- добавлена фирменная иконка CNDL_chat+ для списка модов;
- иконка выполнена в фиолетовой палитре с чат-пузырём и символом `C+`.

## 0.4.0

- проверка обновлений перенесена с запуска клиента на фактический вход на сервер;
- проверка выполняется только один раз за запуск Minecraft;
- окно обновления больше не появляется в главном меню или во время подключения.

## 0.3.14

- добавлена асинхронная проверка новой версии через `version.json` на GitHub;
- добавлено информационное окно с текущей и новой версиями;
- добавлена кнопка открытия прямой ссылки на актуальный JAR;
- ошибки сети не блокируют запуск мода.

## 0.3.13

- уведомление появляется только после подтверждённого перехода друга из офлайна
  в онлайн в рамках текущего подключения;
- начальная синхронизация списка сервера увеличена до 30 секунд;
- офлайн-состояние подтверждается в течение 5 секунд, чтобы исключить скачки TAB-списка.

## 0.3.12

- при подключении к серверу уже находящиеся онлайн друзья больше не вызывают
  визуальные и звуковые уведомления;
- добавлен 10-секундный период стабилизации списка игроков после входа.

## 0.3.11

- возвращено отображение точного времени и даты последнего входа друга;
- количество неактивных дней используется только при отсутствии точного времени.

## 0.3.10

- громкость звука входа друга уменьшена до 75%;
- убрана кнопка ручного `/clan lookup` во вкладке друзей.

## 0.3.9

- звук входа друга заменён на хорошо различимый сигнал повышения уровня;
- масштаб уведомления уменьшен со 125% до 115%.

## 0.3.8

- добавлено скрытие латинской строки `KDR:` из ответа `/clan lookup`;
- громкость уведомления о входе друга увеличена до 100%;
- текст и рамка уведомления о входе друга увеличены.

## 0.3.7

- исправлена привязка отдельных полей к кнопкам ЛС и почты;
- ЛС отправляется через `/w ник сообщение`, почта — через `/mail send ник сообщение`;
- перехват `/clan lookup` теперь продолжается до конца всего блока;
- пустые служебные сообщения и строки статистики скрываются независимо от порядка ответа.

## 0.3.6

- к уведомлению о появлении друга онлайн добавлен тихий короткий звук.

## 0.3.5

- почтовая команда исправлена на `/mail send ник сообщение`;
- фильтр `/clan lookup` адаптирован под многострочный ответ сервера со статистикой;
- значение последней активности читается из строки `Неактивен`.

## 0.3.4

- добавлено краткое HUD-уведомление `ник в сети!`, когда друг появляется онлайн.

## 0.3.3

- расширено скрытие служебного блока ответа `/clan lookup`;
- для почты добавлено отдельное, независимое от ЛС поле ввода.

## 0.3.2

- ответы автоматической проверки `/clan lookup` больше не выводятся в чат;
- для почты добавлен ввод текста и отправка через `/mail send ник сообщение`.

## 0.3.1

- исправлено распознавание глобального маркера `(!)`;
- ответы на сообщения Discord-моста направляются в глобальный чат через `!`;
- добавлены дата последнего входа через `/clan lookup`, почта через `/mail send`
  и отключаемый HUD онлайн-друзей;

## 0.3

- добавлена вкладка друзей с командами `/w`, `/pay` и `/call`;
- добавлены онлайн-статусы друзей;
- добавлены маски `*` в чёрный список слов;
- кнопка Discord-мута перенесена рядом с обычным мутом;
- добавлены пояснения при наведении на кнопки;
- улучшено оформление репозитория и документация.

## 0.2

- добавлены клановый чат, Discord-муты и чёрный список слов;
- расширен GUI и добавлена градиентная подпись CNDL.

## 0.1.0

- первая публичная версия автоответчика.

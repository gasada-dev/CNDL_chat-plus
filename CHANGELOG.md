# История изменений

## 0.9.0 — 2026-09-03

- добавлен единый экран глобальных настроек функций мода;
- вкладки чата, поиск, timestamps, объединение повторов и контекстное меню отключаются независимо;
- переключатели Discord-чата и HUD друзей перенесены из рабочих вкладок в настройки;
- добавлены независимые переключатели звука появления друга и входящего запроса ТП;
- выбор и управление серверными шаблонами перенесены внутрь настроек.

## 0.8.5 — 2026-09-03

- окно обновления увеличено и показывает основные изменения новой версии;
- добавлена подтверждаемая ссылка на полный `UPDATE_NOTES.md` точного release-тега;
- GitHub Release использует `UPDATE_NOTES.md` как единственный источник release notes;
- ожидание ответа `/clan lookup` увеличено с 7 до 15 секунд.

## 0.8.4 — 2026-08-31

- фоновый lookup друзей автоматически запускается через 30 секунд после подключения или раньше при открытии вкладки друзей;
- друзья проверяются по порядку группами по пять с интервалом 10 секунд и паузой 60 секунд, а lookup без ответа повторяется один раз.
- одинаковые player/system сообщения подряд объединяются в одну строку со счётчиком повторов и временем последнего повтора.

## 0.8.3 — 2026-08-31

- online-друзья подняты вверх списка, offline-друзья отсортированы по времени последнего посещения;
- HUD показывает не более 15 online-друзей, сохраняя их полное количество в заголовке.

## 0.8.2 — 2026-08-29

- добавлен автоприём запросов телепорта от всех, друзей или выбранных друзей;
- на Vanilla-box `Alt+ПКМ` по игроку открывает действия с текущим приватом и торговцем;
- добавлена многостраничная подсказка с возможностями и управлением модом;
- список друзей на высоком экране расширен до восьми строк;
- исправлены положение заголовка и подпись `created by CNDL`.

## 0.8.1 — 2026-08-18

- настройки каналов перенесены из повседневного экрана F8 в редактор серверного шаблона;
- пустые хвостовые строки фонового `/clan lookup` больше не остаются в чате с timestamp.

## 0.8.0 — 2026-08-18

- автоматические ответы и периодические отправки вынесены из CNDL_chat+ в приватный
  [CNDL_toolkit 0.1.0](https://github.com/gasada-dev/CNDL_toolkit/releases/tag/v0.1.0);
- F8 теперь открывает менеджер чата с тремя разделами: каналы, чёрный список и друзья;
- legacy-поля automation остаются в config и server templates как неактивный migration bridge:
  CNDL_chat+ сохраняет их, но не показывает и не исполняет;
- выборочный import больше не предлагает rules/periodic categories и сохраняет automation-данные target;
- версия содержит breaking extraction: сначала установите CNDL_chat+ 0.8.0, затем
  CNDL_toolkit 0.1.0; toolkit открывается по F9.

## 0.7.2 — 2026-08-18

- добавлена HUD-кнопка принятия входящего запроса телепорта с таймером 60 секунд;
- клик в открытом чате отправляет настроенную команду `/tpaccept` активного шаблона;
- новый запрос сопровождается точным встроенным звуком шалкера `ambient4`;
- настройки запроса и команды добавлены в шаблоны Vanilla-box и Vanilla-game без скрытого fallback.

## 0.7.1 — 2026-08-17

- название унифицировано как CNDL_chat+ в Fabric ID, resources, Java package и release links;
- GitHub repository и встроенная проверка обновлений переведены на `gasada-dev/CNDL_chat-plus`;
- старые config, imports и история безопасно копируются в новые `cndl-chat-plus-*` пути.

## 0.7.0 — 2026-08-17

- добавлена сохраняемая per-server история чата с настраиваемым лимитом больше vanilla 100;
- добавлены timestamps и вкладки глобального, локального, кланового, личного, Discord и системного чата;
- добавлены непрочитанные счётчики и поиск сообщений через `Ctrl+F`;
- добавлено контекстное меню сообщения по ПКМ с copy, действиями игрока и командами active template;
- поддержаны Minecraft 1.21.11 и 26.2 через target-specific chat mixins;
- улучшено описание мода в списке Fabric-модов.

## 0.6.1 — 2026-08-17

- все экраны и HUD друзей переведены на единую тёмную тему с фиолетовым акцентом:
  flat-кнопки с hover-подсветкой, поля ввода с акцентной рамкой при фокусе;
- активная вкладка главного экрана и редактора шаблонов подчёркивается акцентной линией;
- цвета статусов, панелей и заголовков собраны в общей палитре `UiConstants`.

## 0.6 — 2026-08-16

- исправлено последовательное обновление last seen всех друзей в `vanilla-box` без сброса очереди;
- во вкладку чёрного списка добавлено описание маски `*` с примером `*нордпорт*`.

## 0.5.8 — 2026-08-15

- update checker принимает фактическое GitHub-кодирование `%2B` в URL release assets.

## 0.5.7 — 2026-08-15

- target directories добавлены в repository для сборки из чистого checkout;
- добавлены отдельные сборки для Minecraft 1.21.11 (Java 21) и 26.2 (Java 25);
- updater и GitHub Release используют два явно именованных JAR для поддерживаемых версий;
- доступ к скрытому экрану периодических сообщений защищён вводом hardcoded-пароля `1239`;
- неверный пароль очищает поле и не открывает настройки рассылок.

## 0.5.5 — 2026-08-15

- `AGENTS.md` сокращён до карты проекта, профильных документов и обязательных контрактов;
- явно закреплено повышение версии для каждого нового функционала;
- исправлены устаревшие сведения о schema, runtime flow и ручных сценариях;
- удалены неиспользуемые runtime overrides, import preview IDs и config helper.

## 0.5.4 — 2026-08-04

- если API VanillaGame не возвращает супруга, экран информации последовательно
  проверяет страницы настроенного `/marry list {page}`;
- команда списка браков и regex строки пары/страницы/пустого списка теперь являются
  настройками серверного шаблона;
- служебный вывод поиска брака разбирается до скрытия, а lookup брака и друзей
  используют общий последовательный coordinator;
- обновление встроенного `vanilla-game` добавляет отсутствующие marriage-настройки,
  не перезаписывая уже заданные пользователем значения.

## 0.5.3 — 2026-08-04

- fallback `/clan lookup` теперь сохраняет и показывает все настроенные поля ответа;
- в редактор шаблона добавлена страница regex-полей информации об игроке для других серверов;
- строки lookup по-прежнему скрыты из обычного чата только после извлечения данных.

## 0.5.2 — 2026-08-04

- старый предустановленный `game`, перенесённый в `vanilla-game`, автоматически
  получает публичный провайдер VanillaGame, если пользователь ещё не выбирал его сам;
- исправлено отображение роли лидера клана: API-boolean больше не выводится как имя.

## 0.5.1 — 2026-08-04

- шаблон `game` безопасно мигрирует в `vanilla-game` с сохранением данных, default и bindings;
- встроенным шаблонам назначены домены `mc.vanilla-game.ru` и `mc.vanilla-box.ru`;
- добавлен отдельный экран информации об игроке с online-подсказками и ручным обновлением;
- профиль VanillaGame показывает клан, брак, посещение, доступные контакты и постройки;
- строительные очки и строка скрытых контактов не отображаются;
- интервал периодических сообщений получил видимую подпись в минутах.

## 0.5 — 2026-08-03

- встроенный шаблон `game` больше не распространяет личный список друзей и историю
  last seen: при первой установке эти категории пусты;
- лицензия проекта изменена на GNU General Public License v3.0 only;
- добавлены правила контрибьюта, кодекс поведения, политика безопасности и GitHub
  templates для pull requests, bug reports и feature requests.

## 0.4.5 — 2026-08-03

- подсказки действий с друзьями показывают команды текущего active template;
- пользовательский шаблон `game` (`mc.vanilla-game.ru`) добавлен в предустановленный каталог без очистки его настроек.

## 0.4.4 — 2026-08-03

- добавлена JUnit 5 infrastructure и characterization/unit/security test suite;
- централизованы text normalization и wildcard matching без изменения legacy semantics;
- добавлены validators для player/Discord/message/amount inputs;
- добавлены server template model, atomic repository, safe migration старого config в `Vanilla-box`, address resolver и immutable active runtime;
- команды, parsers, filters, responder guards/rules, friends/HUD и periodic scheduler переведены на active template services;
- добавлены template management UI и подтверждаемый выборочный import с preview;
- `ResponderScreen` получил верхний selector шаблона с кнопкой настроек; скрытая periodic zone закреплена в `(0,0)` размером `15×15`;
- template editor теперь редактирует команды сервера и Discord patterns, добавлены bundled templates и безопасная пользовательская папка загрузки;
- `UpdateChecker` читает latest GitHub Release и проверяет соответствие numeric tag и JAR asset;
- GitHub Actions автоматически публикует проверенный основной JAR при push тега `v<mod_version>`.

# Участие в разработке CNDL_chat+

Спасибо за желание помочь проекту. Перед началом прочитайте `AGENTS.md`, профильную
документацию в `docs/` и открытые issues.

## Лицензирование вклада

Отправляя код, документацию, тесты или другие материалы в этот репозиторий, вы
подтверждаете, что вправе это сделать и соглашаетесь лицензировать свой вклад на
условиях GNU General Public License v3.0 only (`GPL-3.0-only`). Не добавляйте код или
ресурсы с несовместимой лицензией.

## Рабочий процесс

1. Создайте отдельную ветку от актуальной `main`.
2. Ограничьте pull request одной подсистемой или одной пользовательской задачей.
3. До изменения существующего алгоритма добавьте characterization tests.
4. Не меняйте формат config без обратной совместимости, backup и миграционных тестов.
5. Каждое изменение, включая документацию и CI, должно увеличивать `mod_version` и
   обновлять `README.md`, `CHANGELOG.md` и краткий `UPDATE_NOTES.md` текущей версии.
6. Выполните `./gradlew clean test build` и `git diff --check`.
7. Заполните checklist pull request и укажите, что проверялось вручную.

Не включайте в commit `build/`, пользовательские config, логи, IDE-файлы, временные
файлы и локальные JAR. В публичных template JSON не должно быть личных списков друзей,
last seen или иных персональных данных, если их публикация не является явной задачей.

## Совместимость и безопасность

Сохраняйте MOD ID, F8, существующий config, inert automation bridge для CNDL_toolkit
и поведение активного серверного шаблона. Серверные команды должны
проходить validators и отправляться только через общий command service. Не публикуйте
уязвимости в обычном issue: используйте порядок из `SECURITY.md`.

Участие в проекте подразумевает соблюдение `CODE_OF_CONDUCT.md`.

# Текст для Telegram

🟣 **CNDL_chat+ 0.4.1 — умный чат-менеджер для Minecraft 26.2 Fabric**

CNDL_chat+ помогает автоматизировать общение на сервере, фильтровать ненужные
сообщения и быстро взаимодействовать с друзьями. Все функции собраны в удобном
GUI, который открывается клавишей **F8**.

🤖 **Автоответчик**

• Создание собственных правил «фраза → ответ»  
• Поддержка масок: `привет*`, `*продам*` и других вариантов  
• Локальный, глобальный, клановый и личный чат  
• Автоматический ответ в тот же канал через `!`, `/.` или `/r`  
• Собственные сообщения не запускают автоответчик  
• Защита от повторов и бесконечных циклов

🔇 **Муты и фильтрация**

• Обычный мут игрока через `/ignoreplayer`  
• Отдельный локальный мут пользователей Discord  
• Полное отключение сообщений из Discord  
• Чёрный список отдельных слов, фраз и масок `*`  
• Скрытые сообщения не вызывают автоответ

👥 **Друзья**

• Сохранённый список и подсказки онлайновых ников  
• Онлайн-друзья подсвечиваются зелёным  
• Последний вход определяется через `/clan lookup`
• Онлайн-друзья отображаются в отключаемом HUD
• При входе друга появляется уведомление `ник в сети!`
• Уведомление сопровождается коротким звуком
• Быстрое ЛС через `/w`  
• Перевод денег через `/pay`  
• Запрос телепорта через `/call`
• Отправка сообщения на почту через `/mail send ник сообщение`

📢 **Дополнительно**

• До трёх независимых периодических рассылок  
• Настраиваемые маркеры каналов под конкретный сервер  
• Подсказки при наведении на кнопки  
• Автоматическое сохранение всех настроек  
• Клиентский мод — установка на сервер не нужна
• Встроенная проверка новых версий через GitHub

⚙️ **Требования:**

• Minecraft 26.2  
• Fabric Loader 0.19.3+  
• Fabric API 0.156.0+26.2 или новее
